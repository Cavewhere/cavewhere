Splay editing — interactive prototype

Variant C plus the full interaction model. The Splays column is now a real cell on every station row; splay readings are editable cells; move and delete hang off small menus with the off-by-one moves listed first; the general move uses pick-a-target mode.

  • Expand: click the chip. Click an empty Splays cell (A1, A3, A5) to start manual entry — it opens with a blank entry row.
  • Edit: click a reading to focus it, then type (or press Enter). Tab/Enter advance distance → azimuth → inclination → next row. Esc cancels.
  • Add: type into the dashed blank row at the bottom of any open cluster; committing grows a fresh blank underneath. Tabbing through the blank row empty exits the cluster — focus lands on the next station's name box.
  • Move / delete one splay: the ⋯ at the end of each splay row (or right-click the row): "Move to…" and "Remove splay".
  • Move / delete the cluster: the ⋯ beside the chip (or right-click the Splays cell): "Move all to…" and "Delete all N splays" — the delete goes through a RemoveAskBox challenge before anything happens.
  • Pick-a-target: after "Move to…", station boxes light up — click one, or press Esc to cancel. The source station is dimmed.
