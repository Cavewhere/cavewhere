Splay rows — DataBox treatments

The first prototype was drawn as an HTML table, so its full-width tinted bands looked fine there — but the real editor is a grid of bordered DataBoxes and the bands read as pasted-in. Each mock below reproduces the actual editor (Theme tokens, 50 px rows, 1 px shared borders, shot boxes straddling row boundaries) and varies only the splay treatment. Chips are clickable in every variant. A2 (6 splays) starts open.
