# CaveWhere 2026.4.4 Release Notes

## New Features

### Import / Export

- **Attach PocketTopo `.top` files** — trips come in as derived trips named by date and comment; DistoX triples are merged by the solve; splays and series joins are kept; references become fixes in a coordinate system you choose; manual or Auto declination is honored; one warning per file lists what was left out and any `N` → `N_` renames (#503)
